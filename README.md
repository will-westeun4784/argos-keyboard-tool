## What Argos Provides

Argos is a focused configuration utility for Bastard Keyboards. It gives users a clear software-based way to work with device settings and adjust keyboard behavior.

The project concentrates on setup and settings management rather than a broad collection of unrelated functions. Use it when you want to organize keyboard options and make ongoing configuration changes through one dedicated interface.
